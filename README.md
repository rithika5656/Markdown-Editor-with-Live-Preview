# Markdown Editor with Live Preview

A simple, elegant markdown editor with live preview built with vanilla JavaScript.

## Features

- 📝 **Live Preview**: See formatted markdown in real-time as you type
- 💾 **Auto-save**: Content is automatically saved to browser's local storage
- 🎨 **Beautiful UI**: Clean, modern design with gradient header and responsive layout
- 📱 **Responsive**: Works on desktop, tablet, and mobile devices
- 🚀 **Fast**: Uses [marked.js](https://marked.js.org/) for quick markdown parsing
- ✨ **Rich Formatting Support**:
  - Headings (h1-h6)
  - Bold, italic, and strikethrough text
  - Lists (ordered and unordered)
  - Code blocks with syntax highlighting
  - Tables
  - Blockquotes
  - Links and images
  - Horizontal rules

## Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with flexbox and gradients
- **Vanilla JavaScript** - No framework dependencies
- **Marked.js** - Markdown parser library (CDN)

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No installation or build process required!

### Installation

1. Clone the repository:
```bash
git clone https://github.com/rithika5656/Markdown-Editor-with-Live-Preview.git
cd Markdown-Editor-with-Live-Preview
```

2. Open `index.html` in your web browser

That's it! The editor is ready to use.

## Usage

1. Type or paste markdown in the left panel
2. See the formatted output in the right panel
3. Your content is automatically saved to browser storage
4. Close and reopen to restore your work

## Markdown Examples

### Headings
```markdown
# Heading 1
## Heading 2
### Heading 3
```

### Lists
```markdown
- Item 1
- Item 2
  - Nested item

1. First
2. Second
3. Third
```

### Code
```markdown
Inline code: `const x = 42;`

Code block:
\`\`\`javascript
function hello() {
  console.log('Hello!');
}
\`\`\`
```

### Links and Images
```markdown
[Link text](https://example.com)
![Alt text](image-url.jpg)
```
